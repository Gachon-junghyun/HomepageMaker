# figma_knowhow.md — 피그마에서 빌린 것, 안 빌린 것

> **뭐냐:** 이 앱이 피그마(와 DevTools·Onlook 류)에서 무엇을 가져왔고, 무엇을 일부러 안 가져왔는지.
> **언제 읽나:** 「피그마엔 있는데 여긴 왜 없지」가 떠오를 때 · UI 를 늘리기 전에.
> **안 담는 것:** 구현 위치(→ `SCHEMA.md`).

⚠️ 아래는 사람이 피그마를 써 본 «경험»과 공개된 기능 설명에서 정리한 것이다. 실측 링크는 없다 (요약만 봄 등급).

## DevTools 에서 빌린 것

- 박스모델 칠하기(padding 초록·margin 주황) — 피그마의 패딩 표시보다 정확해서 이쪽을 택했다.
- computed style 을 패널 값으로.

## Onlook·v0 류(코드 캔버스 편집기)에서 빌린 것

- 「요소 선택 → AI 에게 그 요소 맥락과 함께 시키기」. 다만 그쪽은 대상 리포에 플러그인(`data-oid`)을 심는다. **여긴 안 심는다** — className grep 으로 되찾는다. 어떤 Next 리포든 그냥 열려야 해서다.

## 피그마에 «없는데» 우리가 만든 것 — 번호 핀

피그마에는 «댓글(Comment)»이 있다. 화면 위 한 점에 말풍선을 남기는 것인데, 그건 **사람이 읽는 메모**다.
여기 핀은 다르다 — 찍는 순간 **그 자리의 DOM 요소**(태그·class·컴포넌트·글)를 같이 붙잡아
프롬프트에 「① = `<h1 class="wordmark…">`」로 적어 보낸다. **읽는 쪽이 사람이 아니라 Claude 라서** 생긴 차이다.

🔴 **그림만 보내면 「빨간 동그라미 친 그거」가 코드의 어디인지 Claude 가 다시 추측해야 하고, 그 추측은 조용히 틀린다.**
핀은 그 추측을 없애려고 있는 것이다. 낙서 도구들(펜·화살표·형광펜)은 «분위기»를 전하고, 핀이 «정확도»를 맡는다.

## 손으로 만지기 (2026-09-12) — PPT 에서 온 것

| PPT·포토샵 | 여기 | 코드로는 |
|---|---|---|
| 모서리·변 손잡이 8개로 크기 | 같음 (Shift = 비율 유지) | `w-[320px] h-[96px]` |
| 안쪽을 끌어 이동 | 같음 | `translate-x-[82px]` (기본) 또는 `ml-[40px] mt-[12px]`(밀기 모드) |
| 위 동그라미로 회전 | 같음 (Shift = 15° 단위) | `rotate-[49deg]` |
| 방향키 1px, Shift 10px | 같음 | 위와 같다 |
| 스마트 가이드(붙임) | 부모·형제의 가장자리·중심에 붙는다. 붙을 게 없으면 8px 격자. Alt 로 해제 | — |
| 선택 상자가 같이 기울어짐 | 같음 (배지도 `1120 × 160 · 49°`) | — |

🔴 **왜 `absolute` 가 아니라 `translate` 인가:** 흐름에서 빼내는 순간 반응형이 죽는다.
`translate` 는 **자리는 그대로 두고 그려지는 위치만** 옮기므로 코드가 안전하고, 겹칠 수는 있다.
«주변을 실제로 밀고» 싶으면 디자인 패널에서 **밀기(margin)** 로 바꾼다 — 둘의 차이를 화면이 말해 준다.

## 일부러 안 빌린 것

- ~~**드래그로 위치·크기 바꾸기.**~~ 🔴 **2026-09-12 에 뒤집었다 — 사람이 「PPT·포토샵만큼의 자유도」를 요청했다.**
  안 빌렸던 이유(픽셀을 끌면 코드가 `absolute` 로 망가진다)는 **버린 게 아니라 우회했다**:
  드래그를 «좌표 박기»가 아니라 **의미 있는 CSS 로 번역**한다 — 이동은 `translate`(흐름 유지) 또는 `margin`(주변을 민다),
  크기는 `width/height`, 회전은 `rotate`. `position:absolute` 는 **여전히 박지 않는다.** 그게 이 설계의 전부다.
  → 아래 §손으로 만지기.
- **컴포넌트 라이브러리 패널.** 리포마다 다르고, 만들면 도메인별 코드가 는다. 필요하면 Claude 에게 「기존 카드 컴포넌트를 써서」로.
- **협업 커서.** 혼자 쓰는 도구다. (댓글은 «번호 핀»으로 다시 지었다 — 위 절)
- **프로토타입 링크.** 홈페이지는 실제 링크가 곧 프로토타입이다 — 선택 도구를 끄면(V) 그냥 클릭된다.
