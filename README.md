# 홈페이지 제작소 (HomepageMaker)

> **뭐냐:** Next.js 홈페이지 리포를 열어 **피그마처럼 보고 고치는** 데스크톱 앱.
> 요소를 클릭해 색·글자·간격을 바꾸면 **소스의 Tailwind 클래스가 바뀌고**,
> 화면에 낙서하고 번호를 찍어 «이거 이렇게» 하면 **Claude 가 그 리포의 파일을 고친다.**
> **언제 읽나:** 이 리포를 처음 볼 때. 작업을 시작할 거면 [`START_HERE.md`](START_HERE.md) 로 간다.
> **안 담는 것:** 구조([`SCHEMA.md`](SCHEMA.md)) · 현재 상태와 지뢰([`HANDOVER.md`](HANDOVER.md)) · 규칙([`START_HERE.md`](START_HERE.md)).

<p align="center"><i>Electron · React 19 · Tailwind 4 · TypeScript</i></p>

---

## 여는 법

```bat
start.cmd
```

처음 한 번은 `app/` 의 의존성을 깔고(≈2분), 그다음부터는 바로 뜬다.
개발 모드(HMR)로 붙으려면 `cd app && npm run dev`.

> **Windows 에서 만들었다.** macOS·Linux 에서 돌려본 적 없다 (`start.cmd` 가 `.cmd` 다).

## 뭘 하나

1. **연다** — 폴더를 고르거나, GitHub 주소로 가져오거나, 템플릿으로 새로 만든다.
   열면 `npm run dev` 가 뜨고 그 화면이 캔버스에 들어온다.
2. **고른다** — 요소를 클릭하면 파란 선택 상자 + 안쪽(초록)·바깥(주황) 여백이 칠해지고,
   왼쪽 레이어에 **React 컴포넌트 이름**이 뜬다. Alt 를 누른 채 호버하면 거리가 나온다.
3. **바꾼다** — 오른쪽 디자인 패널에서 값을 만지면 화면에 **즉시** 먹고,
   「코드에 적용」을 누르면 **소스의 Tailwind 클래스**가 바뀐다.
   그 요소를 소스에서 **유일하게** 못 찾으면 **안 고치고** Claude 에게 넘긴다 — 추측해서 엉뚱한 줄을 고치지 않는다.
4. **말한다** — 요소를 고르고 「이 버튼을 브랜드색으로」. 그림을 끌어다 놓고 「이 느낌으로」.
   `claude -p` 가 **그 리포 폴더 안에서** 파일만 고친다.
5. **낙서한다** — 말로 설명하기 어려우면 화면에 직접 그린다. 아래 절.
6. **올린다** — Git 탭에서 바뀐 파일·diff 를 보고 커밋·push. **누르는 건 사람이다.**

## 낙서 — 번호 핀이 본체다

화면 위에 펜·화살표·동그라미·형광펜으로 그리고, **번호 핀 ①②③** 을 찍는다.
핀을 찍는 순간 앱이 **그 자리에 무엇이 있는지**(태그·class·컴포넌트·글)를 붙잡아 두고,
핀 옆에 적은 메모는 그대로 요청문 초안이 된다. 보내면 프롬프트에 이렇게 적혀 나간다:

```
첨부한 화면 그림 위의 번호 핀 (이 번호가 무엇을 가리키는지는 아래가 정답이다):
- ① 「이 메뉴를 더 크게」 — <div class="wrap flex min-h-[78svh] …"> 글: "개인 비서 하네스…"
- ② 「여기는 지워줘」 — <h1 class="wordmark mt-7 font-bold …"> 글: "DeGaJa Agent"
```

**그림만 보내면 「빨간 동그라미 친 그거」가 코드의 어디인지 다시 추측해야 하고, 그 추측은 조용히 틀린다.**
핀은 그 추측을 없애려고 있다.

## 설계에서 물러서지 않는 것 넷

- 🔴 **대상 리포를 오염시키지 않는다.** 화면의 요소 → 소스 줄을 찾는 건 **className 문자열 grep** 이다.
  바벨 플러그인도 소스맵도 그쪽 리포에 안 심는다 — 그래야 **아무 Next.js 리포나 그냥 열린다.**
  앱이 남기는 건 `.homepage-maker/`(첨부·낙서 그림) 하나뿐이고, 만들 때 `.gitignore` 에 스스로 등록한다.
- 🔴 **되돌릴 수 없는 건 사람이 누른다.** push(=배포)·발행. 앱 안의 Claude 는 커밋조차 하지 않는다.
- 🔴 **Claude 에게 주는 건 파일 도구까지다.** 셸(Bash)은 사람이 토글로 켠 턴에만, cwd 는 그 리포 폴더로 묶인다(`--add-dir` 없음).
- 🔴 **눈으로 확인한 것만 ✅.** 앱은 자기 화면을 찍어 검증한다:
  `HM_AUTOTEST=<리포경로> npx electron .` → `%TEMP%\hm-autotest\` 에 스크린샷과 로그.

## 필요한 것

| | |
|---|---|
| Node.js | 20+ (24 에서 만들었다) |
| Git | 리포를 열고 커밋·push 하는 데 쓴다 |
| [Claude Code](https://claude.com/claude-code) | `claude` CLI 가 PATH 에 있고 **로그인돼 있어야** AI 편집이 된다 |
| 대상 리포 | **Next.js(App Router) + Tailwind**. 토큰 탭은 Tailwind 4 의 `@theme` 를 읽는다 |

```
RESEARCH/     피그마에서 뭘 빌렸고 뭘 일부러 안 빌렸나
```
